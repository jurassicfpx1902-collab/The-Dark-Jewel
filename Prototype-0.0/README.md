# Prototype 0.0

A clean starting point for **The Dark Jewel**, focused on the main menu before adding gameplay systems.

## Features

- English is the default language.
- Portuguese can be selected in Settings.
- Audio state can be toggled and is saved locally.
- Start, Settings, Credits and Exit menu actions are present.
- Olive green and dark blue visual direction inspired by tactical stealth interfaces.

## Run locally

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/Prototype-0.0/
```

The `START` action is intentionally a placeholder until the first gameplay scene is added.
