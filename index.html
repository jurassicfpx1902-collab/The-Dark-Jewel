01 — VISÃO DO PROJETO

Visão do Projeto

The Dark Jewel é um jogo 2D de infiltração, espionagem e narrativa, ambientado no Universo W.B.

O projeto não deve ser tratado apenas como uma sequência de missões independentes.

Cada missão deve contribuir para uma história maior, apresentando personagens, organizações, conflitos, decisões e acontecimentos que gradualmente revelem o verdadeiro significado da operação.

A adaptação de 2001:Eclipse será utilizada como uma das principais bases narrativas do projeto.

A intenção é que o jogador não apenas complete objetivos.

«Controlar ou ser controlado?»

Essa pergunta deve acompanhar a experiência e ganhar novos significados conforme a história avança.

02 — OBJETIVO

Objetivo do Prototype 0.2

O Prototype 0.2 terá como prioridade transformar a demonstração atual em uma verdadeira base de desenvolvimento para o jogo.

  • Melhorar drasticamente os controles
  • Tornar o movimento mais natural
  • Melhorar a interação com o cenário
  • Criar uma infiltração mais consistente
  • Melhorar a inteligência e movimentação dos inimigos
  • Construir uma estrutura narrativa dentro das missões
  • Introduzir elementos de 2001:Eclipse
  • Criar identidade própria para The Dark Jewel
  • Preparar a estrutura para futuras missões
  • Criar uma base técnica que possa crescer sem precisar reconstruir o jogo inteiro
03 — CONTROLES

Controles

Os controles atuais serão revisados.

  • Movimento
  • Agachar
  • Interagir
  • Entrar em esconderijos
  • Sair de esconderijos
  • Observar o ambiente
  • Interagir com objetos
  • Usar equipamentos disponíveis
  • Acessar rádio/comunicação
  • Pausar

O controle deve funcionar principalmente em dispositivos móveis, mas também permanecer compatível com teclado.

PRINCÍPIO

O jogador não deve lutar contra os controles.

A dificuldade deve vir da situação apresentada pelo jogo, e não de comandos imprecisos.

05 — CENÁRIO

Cenário e Exploração

O cenário deve deixar de funcionar apenas como uma sequência de corredores.

Os ambientes precisam transmitir a sensação de que a instalação realmente possui uma função.

  • Escritórios
  • Depósitos
  • Corredores
  • Áreas de segurança
  • Salas técnicas
  • Áreas externas
  • Veículos
  • Caixas
  • Armários
  • Mesas
  • Equipamentos
  • Portas
  • Janelas
  • Áreas restritas

Objetos importantes podem possuir pequenas interações ou observações.

Buck: "Não posso passar por aqui."

Essas pequenas observações ajudam a construir o mundo sem interromper completamente a ação.

06 — ESCONDERIJO

Sistema de Esconderijo

O cenário deve permitir que o jogador utilize determinados elementos como esconderijos.

ARMÁRIO

  • Buck desaparece visualmente do campo de visão dos inimigos
  • O jogador pode observar parcialmente o ambiente
  • O movimento fica limitado
  • Determinadas ações podem revelar a posição do jogador

O sistema deve ser utilizado para criar tensão e não simplesmente como uma mecânica obrigatória.

Sistema de Detecção

Os inimigos devem possuir uma percepção mais natural.

  • Distância
  • Linha de visão
  • Obstáculos
  • Movimento do jogador
  • Postura do jogador
  • Comportamento anterior do jogador
  • Estado de alerta da área

08 — IA

Inteligência dos Inimigos

Os inimigos devem parecer agentes procurando alguém, e não objetos seguindo uma linha.

  • Alterar rotas
  • Investigar ruídos
  • Procurar em áreas próximas
  • Verificar esconderijos
  • Reagir a portas abertas
  • Reagir a objetos deslocados
  • Comunicar suspeitas
  • Aumentar o nível de segurança

O comportamento deve continuar simples o suficiente para funcionar bem no protótipo.

12 — 2001:ECLIPSE

2001:Eclipse

2001:Eclipse será utilizado como uma das bases fundamentais para a narrativa de The Dark Jewel.

A adaptação não deve simplesmente transformar a história original em uma sequência de fases.

Ela deve traduzir seus acontecimentos para a linguagem de um jogo de infiltração.

Elementos narrativos, personagens, organizações e acontecimentos de 2001:Eclipse deverão ser incorporados progressivamente.

  • Diálogos
  • Rádio
  • Documentos
  • Registros
  • Ambientes
  • Objetos
  • Eventos durante as missões
  • Descobertas opcionais
  • Consequências
13 — DOCUMENTOS

Documentos e Informações

O jogador poderá encontrar informações durante as missões.

Um documento não precisa explicar tudo.

  • Um nome
  • Uma organização
  • Uma localização
  • Uma data
  • Uma operação
  • Uma informação parcialmente censurada
  • Uma referência aparentemente insignificante

Posteriormente, essas informações poderão adquirir outro significado.

14 — ESCOLHAS

Escolhas

The Dark Jewel não deve transformar escolhas em simples opções de BOM / MAU.

  • Seguir uma ordem
  • Questionar uma ordem
  • Ignorar uma informação
  • Investigar algo
  • Prosseguir rapidamente
  • Arriscar-se para descobrir mais

As consequências podem não ser imediatamente apresentadas.

O jogador deve poder terminar uma missão sem saber completamente o impacto de sua decisão.

15 — TEMA CENTRAL

Controlar ou Ser Controlado

Esse conceito deve funcionar como um dos pilares narrativos.

  • Controle sobre o personagem
  • Controle através de ordens
  • Controle de informações
  • Controle de organizações
  • Controle político
  • Controle tecnológico
  • Controle sobre a verdade
  • Controle sobre as próprias escolhas
A pergunta central não precisa possuir uma resposta simples.

O jogo deve permitir que o jogador construa sua própria interpretação.
